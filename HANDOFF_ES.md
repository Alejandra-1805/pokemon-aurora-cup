- Proyecto existente: pokemon-aurora-cup / equipo an-256f.

- Repositorio GitHub: https://github.com/Alejandra-1805/pokemon-aurora-cup. Usa el proyecto Vercel existente para conservar su configuración.
- Para dar permiso a otra persona se necesita su usuario GitHub y agregarlo como colaborador; un enlace no concede escritura.
- Al conectar GitHub a Vercel, cada push/merge a main se despliega automáticamente.
- No contiene claves privadas, semillas de wallets ni credenciales de Vercel.
- No implementa pagos cripto ni protección absoluta contra bots.
